# Fisher-Yates Shuffle Algorithm

## Overview

This repository contains my implementation, analysis, and proof of the Fisher-Yates Shuffle Algorithm. The project includes:

* Java implementation
* Mathematical proof of uniform randomness
* Explanation of why the Naive Shuffle Algorithm is biased
* Time  Complexity Analysis
* Handwritten proof notes


## Complexity

| Operation | Complexity |
| --------- | ---------- |
| Shuffle   | O(n)       |
| Space     | O(1)       |
